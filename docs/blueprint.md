# **App Name**: نافذة السمع

## Core Features:

- Authentication: User authentication and profile management.
- Audiobook Catalog: Browse, search, and view details of audiobooks including cover, title, author, narrator and duration.
- Audiobook preview: Preview the start of the audiobook.
- Category Browsing: Categorized listing of audiobooks
- Audiobook Management: Admin panel to add, edit, and manage audiobooks.
- Arabic (RTL) support: Provide full support for the Arabic language (RTL layout).

## Style Guidelines:

- Primary color: Desaturated orange (#D4A273) to convey warmth and culture without being overwhelming.
- Background color: Dark gray (#212121) for a sophisticated feel, that fits the literary and slightly formal aspect of the app. 
- Accent color: Blue-gray (#7380D4), which is analogous to orange and gives an impression of clarity, knowledge, and safety.
- Body and headline font: 'Literata' (serif), conveying a literary and slightly formal quality.
- Simple, clear icons for navigation and controls.
- Ensure that elements and text fully support right-to-left (RTL) layouts.
- Use smooth transitions when loading content.
